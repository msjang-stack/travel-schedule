# 길눈 — 국내 여행 동선 플래너

지역·여행 일수·인원 수·인원 구성을 고르면 그 지역의 **명소·맛집·카페를 동선 순서로** 엮은
하루 일정을 만들어 주는 정적 웹앱입니다.

## 기능

1. **지역 선택** — 서울·부산·제주·경주·강릉·전주·여수·속초·통영·춘천/가평·안동·포항·인천/강화
   (13개 지역). 각 지역 카드에 대표 풍경 일러스트
   (Higgsfield 생성 이미지로 교체 가능 — [docs/HIGGSFIELD.md](docs/HIGGSFIELD.md))
2. **조건 선택** — 여행 일수(1~3일), 인원 수, 구성(혼자·친구·연인·가족)
3. **동선 일정** — 권역(zone) 단위로 하루를 묶고, 오전 명소 → 점심 → 오후 → 카페 → 저녁 → 밤
   순서로 최근접 이웃 방식 동선을 구성
4. **장소 팁** — 각 장소의 주차 가능 여부, 티케팅·예약 방법, 웨이팅 요령 정리
5. **이동 UI** — 장소 사이 이동 수단(도보/차량)·예상 소요시간·거리 표시, 하루 동선 SVG 지도
6. **3D 동선 재생 (Three.js)** — 지도를 누르면 실제 지형 위에 선 도시를 카메라가 따라가며
   방문 순서대로 이동을 재생한다. 도착할 때마다 장소 카드(주차·발권·웨이팅)가 뜬다.
   - 렌더링: Three.js(r149, `js/vendor/`에 포함 — CDN 의존 없음)로 실시간 그림자,
     방향광·반구광, ACES 톤매핑, 거리 안개, 물 노멀맵 물결을 사용한다.
   - 지형: `js/terrain.js`의 실제 해안선·한강·호수·산 좌표로 지형 메시를 만든다.
     산은 높이를 가진 메시라 건물·나무·동선·캐릭터가 그 위에 실제로 올라간다.
     거리별 LOD로 가까운 곳만 촘촘히 깎는다.
   - 여행자: 머리·몸통·팔·다리가 분리된 캐릭터가 걸을 땐 팔다리를 흔들며 걷고,
     차량 구간에선 바퀴가 구르는 차에 앉아 이동한다.
   - 도시: 타워(옥탑·안테나)/판상 아파트/박공집/한옥/차양 상가 등으로 나뉘고,
     권역 성격(해변·항구·유적·시장·산)과 지역별 도시 밀도(`urbanity`)에 맞춰
     종류·높이·밀도가 달라진다. 시골 지역에는 빈 땅에 논밭이 깔린다.
     창문 텍스처가 입혀지고 밤에는 창에 불이 켜진다.
   - 조작: 재생/일시정지, 속도(1~4×), 진행 바, 핀 클릭 이동, 드래그 회전, 휠·핀치 확대,
     **WASD·방향키·모바일 조이스틱 자유 이동**. WebGL 미지원 기기에는 안내를 표시한다.

## 실행

빌드 과정 없는 순수 정적 사이트입니다.

```bash
# 아무 정적 서버로 열기
python3 -m http.server 8000
# → http://localhost:8000
```

배포: GitHub Actions 워크플로(`.github/workflows/deploy-pages.yml`)가 푸시 시 GitHub Pages로 자동 배포합니다.
배포 주소: https://msjang-stack.github.io/travel-schedule/

## 구조

```
index.html          앱 골격 (3단계 SPA)
css/style.css       디자인 토큰(라이트/다크) + 레이아웃
js/data.js          지역·장소 데이터 (좌표, 주차/발권/웨이팅 정보)
js/app.js           동선 생성 로직 + 렌더링
js/map3d.js         3D 동선 맵 (Three.js 렌더러 + 이동 재생 + 자유 이동)
js/vendor/          three.min.js (r149, MIT) — CDN 없이 로컬 포함
js/terrain.js       지역별 실제 지형 (해안선·강·호수·산), 장소 지형 분류
js/higgsfield.js    지역 SVG 아트 + Higgsfield 이미지 연동 훅
docs/HIGGSFIELD.md  Higgsfield 이미지 생성·적용 가이드
```
